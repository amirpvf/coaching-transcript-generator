Coaching Mentoring Session Transcript Generator

Upload a recorded session and get a complete, time-stamped transcript, split into coach and client, in the mentor’s Word template.

Your audio goes straight from your own device to ElevenLabs and is never sent to any other server, including the maker of this page. The Word file is built on your own device.

1ElevenLabs key

Needed only once. Each person’s free account includes about 4.5 hours a month, roughly four one-hour sessions.

The key is kept only in this browser on your device, so you don’t have to enter it again. It is sent nowhere except ElevenLabs itself.

Illustrated guide to creating a key (about 10 minutes, once)
⚠️ ElevenLabs is not reachable from Iran without a VPN — both when signing up and every time you use this tool.

1Turn on a VPN (if you are in Iran)

ElevenLabs blocks Iranian IP addresses. Turn your VPN on first and keep it on until you finish.

2Create a free account

Go to elevenlabs.io and tap Sign up.

  • Easiest: Continue with Google
  • Or use your email and open the confirmation message

3Choose a platform

If you see “Choose your platform”, pick the top card, ElevenCreative, and tap Continue.

  • You can switch later

4Skip the welcome questions

You may be asked how you plan to use it. Pick anything or tap Skip.

5Open the API keys page

Open the keys page and tap Create API Key:

  • Open the API keys page ↗
  • If it doesn’t open: bottom-left menu → Developers → API Keys

6Set permissions

Give it any name, for example coaching-transcript. In the permission list:

  • Speech to Text → Access
  • Everything else → No Access (safer)
  • Then tap Create

7Copy the key

The key starts with sk_ and is shown only once. Tap Copy, come back here, paste it into the key box and tap “Save key”.

  • Never share your key — treat it like a password

Privacy: the technical details, for anyone who wants to be sure

There is no server

This tool is just a few static files that GitHub Pages delivers to your browser. There is no server, database or user account behind it. All the work happens inside your own browser.

Where exactly does the audio go?

Only, and directly, from your browser to api.elevenlabs.io, using your own key. Neither the maker of this page nor GitHub sees it.

Where is the Word file made?

In your browser’s memory, then downloaded straight to your device. No copy is uploaded or stored anywhere. Closing the page clears the transcript from memory.

Where is the key kept?

In this browser’s local storage on your device. “Remove key” deletes it completely.

A browser-enforced lock

The page carries a Content Security Policy that tells your browser it may not connect to any address except api.elevenlabs.io. Even if someone later added code to send data elsewhere, the browser would block it unless that policy were openly changed too.

No trackers

No analytics, cookies, ads, or third-party fonts and libraries; the font and the Word-building library are served alongside the page itself.

Check it yourself

  • The full code is readable in the public GitHub repository.
  • On a computer, open Developer Tools → Network and make a transcript: the only outside request is to api.elevenlabs.io.

One honest caveat

ElevenLabs itself receives the audio in order to transcribe it, under its own privacy policy. Mention in your client’s consent that the recording is processed by an AI transcription service.

Before you send it to your mentor:
